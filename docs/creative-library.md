# Creative Library

The London creative library is a first-class glossary and reference surface for
design terms, anti-patterns, tools, schools, and product concepts. It combines
curated London vocabulary with optional evidence from the sanitized SQLite
brain.

The library is intentionally specific. It should explain why a term matters,
when to use it, and what to avoid. Tests fail if the surface collapses into
generic "modern clean" design filler.
