## London's Brain Query

Portable — works on any machine where `london` is installed:

```bash
london brain query "your research question"
```

When running inside Claude Code with the brain MCP mounted, call the `london_brain_query` tool instead (it returns full findings, no filter).

Run at minimum 2 queries per research phase. Document findings.
