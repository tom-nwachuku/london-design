Bundled London Type Shelf starter fonts.

These WOFF2 files are the package-owned `bundled_open` lane used for
launch-proof font loading. Their source, license, checked date, import
reference, and SHA-256 hash are recorded in `../type_shelf.json`.

Closed-source, paid, or commercial reference faces do not live in this folder.
Those belong in the shelf metadata as `reference_visual` entries with public
specimen and buy/license links; London may show the recommendation, but the
package must not redistribute a non-bundled font binary or pretend it loaded.
